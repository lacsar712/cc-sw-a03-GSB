校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

## 同灯互斥台

顶栏「同灯互斥台」（http://localhost:3195/mutex）整页分三块：**冲突监视栏 / 在途同灯栏 / 历史已结案栏**，下方为可按灯回翻的**互斥流水**。

规则：同一灯种同时只允许一个未结（pending）编号。提交前先查该灯是否仍有未结编号——有则拒收（页面内嵌标红，非弹窗）并列出冲突编号；结案后才允许同灯再开。每次「放行 / 冲突拒收」都记一条流水。worker 领到单后默认保持在途约 6 秒（`HOLD_SECONDS` 可调）再结案，便于观察互斥窗口。

1. calibrator 进互斥台，先投「氖灯」→ 进入在途同灯栏（待处理）。
2. 立刻再投同一「氖灯」→ 被拒收，页面标红并显示冲突号（在途那一单的编号）；流水出现「冲突拒收」，冲突监视栏该灯拒收次数 +1。
3. 约 6 秒后第一单结案：在途同灯栏清空，旧单进入历史已结案栏。
4. 再投同一「氖灯」→ 应收下（放行），新单进入在途；流水出现「放行」。
5. inspector 登录可查看三块与流水，看不到提交框，强发提交接口返回 403。
