# 光谱波长校准台

校准员提交标称波长与实测波长。独立领取进程按允差写出合格或超差。页面轮询直到结论出现。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3195 |
| 接口 | http://localhost:8195 |
| PostgreSQL | localhost:54395 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| calibrator | calib123456 | 可提交校准 |
| inspector | insp123456 | 只看 |

## 启动

```bash
docker compose up --build
```

## 互斥台

顶栏「互斥台」进入整页：冲突监视栏 / 在途同灯栏 / 历史已结案栏 三块，另有冲突与放行流水（可按灯回翻）。

- 同一灯种同时只允许一单在途；提交前检查该灯是否仍有未结编号，有则拒收并列出冲突号（页内标红），结案后才允许同灯再开。
- 结案：在途单由校准员点「结案」立即出结论；领取进程也会按节拍（`WORKER_INTERVAL`，默认 5 秒）自动结案。
- 冲突与放行各记一条流水。巡检员（inspector）可看三块与流水，不可提交、不可结案。

## 验收

1. calibrator 登录后，种子「氦灯-587」合格、「汞灯-546」超差。
2. 互斥台投「氖灯-640」进在途，立刻再投同灯：被拒收，页内红条列出冲突号，冲突监视栏新增一条。
3. 第一单结案（点「结案」或等领取进程）后，再投同灯被收下；历史已结案栏出现旧单，在途栏清空。
4. 流水区按「氖灯-640」回翻，可见冲突与放行两条。
5. inspector 登录可看三块与流水，但无提交与结案入口（接口亦 403）。
